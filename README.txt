KRYPTON WEBSITE STARTER

Files:
- index.html: home page
- services.html: services page
- about.html: about page
- contact.html: contact page
- styles.css: supplied stylesheet
- app.js: supplied site functionality

RUN ON WINDOWS:
1. Extract this ZIP into a folder.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted krypton_website folder.
4. Install the "Live Server" extension by Ritwick Dey if needed.
5. Open index.html, right-click in the editor, and choose "Open with Live Server".

IMPORTANT:
- The website's contact form currently sends to hello@kryptonsec.com via FormSubmit, as configured in app.js. Change that address to an inbox you control before using the form. FormSubmit may require one-time email activation on the first submission.
- The contact details, phone number, social links and company claims should be verified/edited before publishing.
- This is a static website; it does not require npm or a build step.
